## 1. 🚨 CRITICAL — 사용자가 실제로 돈을 잃는 경로 (3개 페르소나가 독립 지목)

### U-01. 재매각 물건인데 입찰보증금을 10%로 표시 (실제 20%)
- **화면**: 상세 상단 KPI `입찰보증금 (통상 10%) 0.90억` (2025타경507316)
- **같은 페이지 아래 법원 원문**: "재매각. 매수신청보증금은 **최저매각가격의 20%**임" → 실제 **1.79억**
- **결과**: 폴드의 큰 숫자만 보고 0.9억 수표를 준비해 법정에 가면 **입찰 자체가 무효**.
  사이트가 자기 페이지 안에서 자기를 반박하고 있다(확정 사실은 스크롤 아래, 추정값은 맨 위 큰 글씨).
- **수정안**: 명세서 비고에서 보증금 비율을 파싱해 반영(`입찰보증금 1.79억 · 재매각 20% 적용`).
  파싱 실패 시 **숫자를 단정하지 말고** "법원 공고 확인 필요(통상 10%, 재매각 시 20~30%)".
- **연결**: 무료 격차 감사 **P-03**이 지적한 `remaeordDay`(재매각=대금미납, raw에 1,232건 보유·미사용)가
  바로 이 피해의 원천이다. "안 쓰는 필드"가 "사용자 손실 경로"로 실증됐다.

### U-02. 직전 낙찰자가 보증금을 날린 물건인데 폴드는 초록 "예상 차익 4.43억"
- 기일 내역: 2026-05-26 **매각 8.96억** → 2026-07-07 대금지급기한 **미납** → 재매각.
  즉 앞선 낙찰자가 약 1.79억을 포기하고 나갔다 = 최대급 경고 신호.
- 그런데 헤더는 "유찰 1회"라고만 쓰고(= '아직 아무도 안 샀다'로 읽힘), '미납'은 4번째 화면 표에 두 글자.
- **수정안**: 제목 옆 붉은 `재매각` 배지 + 요약줄 "유찰 1회 · **매각 후 대금미납 1회(재매각)**" +
  상단 경고 배너 첫 문장을 이 물건 고유 사실로 교체. 목록 카드에도 `재매각` 칩.

### U-03. 낙찰 후 '잔금' 안내가 사이트 전체에 0회
- 목록·상세·가이드 HTML에서 **'잔금' 0회 · '낙찰 후' 0회 · '입찰 절차' 0회**.
- 상세는 "입찰보증금 0.90억"을 크게 보여주지만, 낙찰 시 **약 1개월 내 나머지 8억을 완납**해야 하고
  못 내면 보증금이 몰수된다는 사실이 문장으로 어디에도 없다(단서는 기일표의 '대금지급기한' 한 줄뿐).
- **수정안**: KPI 밴드 아래 "낙찰되면 실제로 필요한 현금" 3단 타임라인
  (입찰 당일 보증금 → 약 1개월 내 잔금 → 소유권 이전 취득세 = 총액), 각 단계에 실제 날짜.

### U-04. 첫 화면 숫자가 클릭하면 전부 달라짐 (실전 투자자: "안 쓰게 되는 1번 이유")
| 칩 배지 | 클릭 후 실제 |

| 인수 없음 · **803** | **434건** |
| 매각기일 임박 · **1817** | **894건** |

- **수정안**: 칩 배지를 **클릭 후 실제로 보게 될 목록과 같은 쿼리**로 계산. 화면당 모집단 숫자는 최대 2개.
- ⚠️ **감사 자신의 갭**: 이건 정합 문제인데 `audit_display.py`가 못 잡았다 — 등급·인수 필드만 비교하고
  **건수·필터 동작**은 대조하지 않았기 때문. 정합 감사에 '칩/요약 건수 vs 실제 결과 수' 검사를 추가해야 한다.

### U-05. CSV가 화면과 다른 데이터를 줌
- `/?region=서울&budget=3` 화면 **145건** vs 같은 조건 `/export.csv` **2,071행**. 무필터는 1,185 vs 14,440.
- 비교 기능이 없어 엑셀이 유일한 우회로인데 그 우회로가 다른 데이터를 준다.
- **수정안**: export.csv에 목록과 동일한 서브셋·정렬·필터 파라미터 전부 반영. 링크 라벨에 건수 병기.

### U-06. 초록 "✓ 인수 없음" 배지 — 모름을 안전으로 승격
- 60장 중 **57~59장**에 부착(변별력 0, 안심 효과 100). 상세는 같은 사실을 "발견 **안 됨**"이라고 신중히 쓰는데
  목록은 "인수 **없음**"으로 단정. 체크표시 + 이익색(초록)이 '검증 완료 인증'처럼 읽힌다.
- 통계 페이지는 "확인된 물건의 45%가 인수 부담"이라고 말하는데, 목록만 본 사용자는 **잘못된 기저율**을 학습.
- **수정안**: "명세서상 인수권리 미발견"으로 문구 강등 + 초록→중립 회색. 초록은 **돈(이익)에만**.
  더 나은 안: '없음'은 무배지, **위험 상태에만 배지**(붉은 "인수 부담", 주황 "권리 미확인").

### U-07. 가장 크게·유일하게 색으로 강조된 숫자가 가장 신뢰도 낮은 숫자
- "예상 차익"은 ⓐ 최저가 그대로 낙찰 가정 ⓑ 양도세·명도비·수리비·미납관리비 전부 제외 —
  두 겹의 가정 위 값인데, 카드에서 가장 눈에 띄고 상세에선 유일하게 초록 하이라이트 박스.
- 정정 문구("차익은 상한 추정치")는 /methodology와 13,000px 아래 각주에만 있다.
- **수정안**: 라벨 "예상 차익" → **"표면 차익(세전)"** 또는 "최저가 낙찰 가정 차익", 값 아래 상시 각주
  "낙찰가 상승·양도세·명도/수리비 미반영", 초록 강조 해제.

### U-08. 임대관계 '미상'인데 초록 패널 "대항력 임차인 발견 안 됨"
