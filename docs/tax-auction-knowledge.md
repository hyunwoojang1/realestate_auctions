# 부동산 경매 세금 지식문서 (기준연도 2026)

> **단일 출처(SSOT)**: 이 프로젝트의 모든 세금 계산·표시는 이 문서를 근거로 한다.
> 코드(`src/tax.py`)의 상수·산식은 이 문서와 1:1 일치해야 하며, 테스트가 이를 고정한다.
> 세법 개정 시 이 문서와 tax.py만 갱신한다(자동 크롤 없음). 최종 검증일: 2026-07-02 (웹 교차확인).

## 0. 대전제 — 경매 취득의 세법상 성격
- **법원경매 낙찰 = 유상승계취득**(원시취득 아님, 판례·과세관행 확립). 따라서 일반 매매와 **동일한 취득세율** 적용.
  - 과세표준 = **낙찰가**(사실상 취득가격). 우리 도구에서는 입찰 전이므로 **최저입찰가**로 추정(보수적 하한, 실제 낙찰가는 그 이상일 수 있음 → 취득세도 그 이상).
- 2016-12 개정: 과세이력 있는 부동산은 원시취득 논리로도 4% (경매 승계취득 정리와 일관).

## 1. 취득세 — 주택 유상취득 (지방세법 §11①8호)
### 1-1. 기본세율 (1주택 / 비조정 2주택 / 일시적 2주택)
| 취득가액 | 취득세율 |
|---|---|
| 6억 이하 | **1%** |
| 6억 초과 ~ 9억 이하 | **(가액 × 2/3억원 − 3) × 1/100** — 소수점 다섯째자리에서 반올림해 넷째자리까지 (1.0001~2.9999%) |
| 9억 초과 | **3%** |

### 1-2. 다주택·법인 중과 (지방세법 §13의2, 취득 후 주택 수 기준)
| 취득 후 주택 수 | 조정대상지역 | 비조정대상지역 |
|---|---|---|
| 2주택 | **8%** (일시적 2주택은 기본세율) | 기본세율(1~3%) |
| 3주택 | **12%** | **8%** |
| 4주택 이상 | **12%** | **12%** |
| 법인 | **12%** (주택 수 무관) | **12%** |

### 1-3. 부가세 (취득세에 항상 얹힘)
- **지방교육세**:
  - 기본세율(1~3%) 구간: `취득세율 × 1/2 × 20%` = **0.1~0.3%**
  - 중과(8%/12%): **0.4% 고정**
- **농어촌특별세** (전용면적 기준):
  - 전용 **85㎡ 이하: 비과세(0%)** — "서민주택"
  - 전용 85㎡ 초과: 기본세율 구간 **0.2%** / 8% 중과 **0.6%** / 12% 중과 **1.0%**

### 1-4. 합계세율 요약표 (주택)
| 케이스 | 85㎡ 이하 | 85㎡ 초과 |
|---|---|---|
| 기본 6억↓ | **1.1%** | **1.3%** |
| 기본 6~9억 | 산식+0.5×산식×20% (≈1.1~3.3% 선형) | +0.2%p |
| 기본 9억↑ | **3.3%** | **3.5%** |
| 8% 중과 | **8.4%** | **9.0%** |
| 12% 중과 | **12.4%** | **13.4%** |

## 2. 취득세 — 주택 외 (오피스텔·상가·업무·토지 등)
- **취득세 4% + 지방교육세 0.4% + 농어촌특별세 0.2% = 합계 4.6%** (유상취득 일률, 주택 수 무관)
- **오피스텔은 세법상 '건축물'** — 주거용으로 쓰더라도 취득 시 **4.6%** (주택 세율 아님).
- 농지(전·답·과수원)는 3.4%(신규 취득 시 감면 요건별 상이)이나, 본 도구는 보수적으로 4.6% 적용(과소추정 방지).

## 3. 목록·스코어 미반영 세금 (→ §5 시뮬레이터에서만 반영)
> **2026-07-23 변경**: 아래 항목들은 목록/스코어의 '표면차익'에는 여전히 미반영이다(사용자 확정 정의 유지).
> 다만 **상세페이지 입찰가 시뮬레이터**(`src/bidsim.py`)는 사용자가 가정을 명시 입력하므로 §5에 따라 전부 반영한다.
> 즉 "주관 개입"이라 못 넣던 값을 **사용자가 직접 고른 가정**으로 바꿔 계산하는 것이 시뮬레이터의 존재 이유다.

### 3-1. 양도소득세 (매도 시)
- 보유 1년 미만 **70%**, 1~2년 **60%**(주택·입주권), 2년 이상 기본세율(6~45%) + 지방소득세 10%.
- 1세대1주택 비과세: 2년 보유(조정지역 취득분은 2년 거주) + 12억 이하.
- **목록 미반영 이유**: 매도가·보유기간·거주 여부 가정 필요 → 주관 개입. "취득 시점 표면차익" 정의(사용자 확정)와 불합치.
- **시뮬레이터 반영**: §5 참조(매도가·보유기간을 사용자가 입력).
### 3-2. 보유세
- 재산세(매년 6/1 소유자 기준, 공시가격×공정시장가액비율×0.1~0.4% 누진), 종부세(주택 공시 합산 9억, 1세대1주택 12억 초과분).
- **미반영 이유**: 보유기간 가정 필요. 6/1 직후 낙찰이면 그 해 재산세는 전 소유자 부담(경매 팁).
### 3-3. 경매 특유 비용 (세금 아님 — 별도 확인 안내)
- **명도비**: 인도명령(매각대금 완납 후 6개월 내 신청 가능) / 강제집행 비용 또는 이사 합의금. 물건별 편차 큼.
- **미납관리비**: 낙찰자는 **공용부분** 체납분만 승계(대법원 판례), 전유부분·연체료는 미승계. 통상 3년분 한도 실무.
- **인지세**(등기 시, 1억↓ 5만/10억↓ 15만 등), **국민주택채권 매입·할인비용**(시가표준액 비례, 즉시매도 할인율 수%), **법무사 보수**.
- **선순위 인수금액**: 대항력 임차보증금·인수 등기 등 — D(권리분석) 배선 후 **객관 값으로 별도 라인** 표시 예정.

## 4. 코드 매핑 (tax.py와 1:1)
- `BuyerProfile(houses_owned, regulated_area, is_corporation)` — 기본 `1주택·비조정·개인`.
- `effective_rates(price, property_type, area_m2, profile)` → (취득세율, 교육세율, 농특세율) — 위 표 그대로.
- `acquisition_tax_breakdown(...)` → {취득세, 지방교육세, 농어촌특별세, 합계} — UI 상세 표시용.
- 주택 판정: `아파트/연립·다세대/빌라/단독·다가구` = 주택, `오피스텔/상가/토지 등` = 비주택(§2).

## 5. 입찰가 시뮬레이터 — 낙찰~매도 전체 비용·양도세 (기준연도 2026)

> `src/bidsim.py`와 1:1. **상세페이지 전용**이며 목록·스코어의 표면차익 정의는 건드리지 않는다(§3 참조).
> 모든 값은 사용자가 조절 가능한 **가정**이고, 기본값은 아래 표를 쓴다.
> 원칙은 §0~§2와 동일하게 **보수적**(불확실하면 비용은 크게, 공제는 작게 잡아 과대추정을 막는다).

### 5-1. 취득 단계 비용
| 항목 | 산식 | 비고 |
|---|---|---|
| 취득세 | §1·§2 (`tax.acquisition_tax`) | **입찰가 변동 시 재계산** — 목록은 최저입찰가 고정, 시뮬레이터는 입력 입찰가 기준 |
| 인지세 | 구간표(5-2) | 정액, 정확 계산 |
| 법무사·국민주택채권 등 | 사용자 입력(기본 **50만원**) | 채권 실부담은 시가표준액 의존 → 단일 조절값으로 단순화·명시 |
| 인수금액 | 권리분석 `badge.assumed` | 대항력 보증금 등, 낙찰가 외 추가 부담 |
| 명도비 | 사용자 입력(기본 **300만원**) | 이사합의금·강제집행. 물건별 편차 큼(§3-3) |
| 수리비 | 사용자 입력(기본 **0원**) | |
| 미납관리비 | 사용자 입력(기본 **0원**) | 공용부분만 승계(§3-3) |

### 5-2. 인지세 구간표 (인지세법 §3, 부동산 소유권이전 증서)
| 기재금액 | 인지세 |
|---|---|
| 1천만원 이하 | 비과세 |
| 1천만 초과 ~ 3천만 이하 | 20,000원 |
| 3천만 초과 ~ 5천만 이하 | 40,000원 |
| 5천만 초과 ~ 1억 이하 | 70,000원 |
| 1억 초과 ~ 10억 이하 | 150,000원 |
| 10억 초과 | 350,000원 |

### 5-3. 대출(경락잔금대출)·보유 비용
- 대출액 = **낙찰가 × LTV** (기본 70%). 실무상 방공제·신용에 따라 낮아질 수 있음 → 상한 80%로 캡.
- 이자 총액 = 대출액 × 연이율(기본 **5.0%**) × 보유개월/12 — **거치식 단순이자**(원금상환 미가정, 보수적).
- 실투자금(자기자본) = 취득 단계 총비용 − 대출액.

### 5-4. 매도 단계 비용 — 중개보수 상한요율 (공인중개사법 시행규칙 별표, 매매)
| 주택 매매가 | 상한요율 | 한도액 |
|---|---|---|
| 5천만 미만 | 0.6% | 25만원 |
| 5천만 ~ 2억 미만 | 0.5% | 80만원 |
| 2억 ~ 9억 미만 | 0.4% | — |
| 9억 ~ 12억 미만 | 0.5% | — |
| 12억 ~ 15억 미만 | 0.6% | — |
| 15억 이상 | 0.7% | — |

- **주거용 오피스텔**(전용 85㎡ 이하): 매매 **0.5%**
- 그 외 비주택(상가·토지·85㎡ 초과 오피스텔): **0.9%** (협의 상한)

### 5-5. 양도소득세 (소득세법 §55·§95·§103, 2026)
**계산 순서**
```
양도차익   = 매도가 − 취득가액(낙찰가) − 필요경비
양도소득금액 = 양도차익 − 장기보유특별공제
과세표준   = 양도소득금액 − 기본공제 250만원
산출세액   = 과세표준 × 세율
총 양도세  = 산출세액 × 1.1   (지방소득세 10% 부가)
```

**필요경비로 인정하는 것 (보수적 범위)**
- ✅ 취득세, 인지세, 법무사보수·채권할인 등 취득 부대비용, **매도 중개보수**
- ❌ **명도비**(실무·판례상 불인정), **미납관리비**, **대출이자**, **수리비**
  - 수리비는 자본적지출(새시·확장·난방교체 등)만 인정되나 수익적지출(도배·장판)과 구분이 입력만으로 불가 →
    **보수적으로 전액 미공제**(세금을 크게 잡는다). UI에 이 가정을 명시한다.

**세율 — 단기 (보유기간 기준)**
| 보유기간 | 주택·조합원입주권 | 그 외 부동산(토지·상가·오피스텔 등) |
|---|---|---|
| 1년 미만 | **70%** | **50%** |
| 1년 이상 2년 미만 | **60%** | **40%** |
| 2년 이상 | 기본세율(아래) | 기본세율(아래) |

> **오피스텔 처리(보수적)**: 취득세는 §2대로 **비주택 4.6%**지만, 양도세 단기세율은 **주택으로 간주**한다
> (70%/60%). 주거용으로 쓰면 실질과세로 주택 판정을 받을 수 있고, 둘 중 **세금이 큰 쪽**을 잡는 것이
> 이 프로젝트의 보수 원칙과 맞기 때문이다. 업무용으로 확정된 오피스텔이면 실제 세금은 이보다 작다.

**세율 — 기본세율 누진표 (소득세법 §55)**
| 과세표준 | 세율 | 누진공제 |
|---|---|---|
| 1,400만원 이하 | 6% | — |
| 1,400만 ~ 5,000만 | 15% | 126만원 |
| 5,000만 ~ 8,800만 | 24% | 576만원 |
| 8,800만 ~ 1억5,000만 | 35% | 1,544만원 |
| 1억5,000만 ~ 3억 | 38% | 1,994만원 |
| 3억 ~ 5억 | 40% | 2,594만원 |
| 5억 ~ 10억 | 42% | 3,594만원 |
| 10억 초과 | 45% | 6,594만원 |

**장기보유특별공제 (§95②, 표1)**
- 보유 3년 이상: **연 2%, 최대 30%**(15년). 3년 미만·단기세율 구간은 **미적용**.
- 1세대1주택 표2(최대 80%)는 **거주기간 가정이 필요해 미적용**(보수적 — 세금을 크게 잡는다).
- 비과세(1세대1주택 12억 이하)도 **미적용** — 다른 주택 보유 여부를 도구가 알 수 없다. UI에 안내만 한다.

### 5-6. 최종 산출
```
세후 순익  = 매도가 − (낙찰가 + 취득세 + 취득부대비 + 인수금 + 명도비 + 수리비
                       + 미납관리비 + 이자총액 + 매도중개보수 + 총 양도세)
자기자본수익률 = 세후 순익 / 실투자금       (실투자금 ≤ 0 이면 산출 불가 → 미표시)
연환산       = 자기자본수익률 × 12 / 보유개월
손익분기 입찰가 = 세후 순익 = 0 이 되는 입찰가   (세후 순익은 입찰가에 대해 단조감소 → 이분탐색)
```

- **손익분기 입찰가**가 이 기능의 결론이다. "차익 3억"이 아니라 "**여기까지 써도 남는다**"가 입찰표에 쓰는 숫자다.
- 산출 결과는 **전부 가정 기반 추정**이며 세무 자문이 아니다. UI에 반드시 명시한다.

**단조감소 전제(이분탐색의 근거)** — 손익분기 탐색은 "세후 순익이 입찰가에 대해 단조감소"를
전제로 이분탐색한다. 입찰가를 1원 올리면 취득세·이자 등 직접비용이 1원 넘게 늘고, 그로 인해
줄어드는 세금은 결합 실효세율(최대: 기본 45% + 다주택 중과 30%p, 지방소득세 10% 가산 = **82.5%**)
이 100%를 넘지 못하므로 증가분을 이길 수 없다. **세 가지 tax_mode(individual/dealer/none)와
다주택 중과 조합 전부에서 성립**한다 — 실측 스윕(4모드 × 138 입찰가 지점, 2026-07-28) 위반 0건.
경비 구성을 바꿀 때는 이 부등식이 유지되는지 먼저 확인할 것(깨지면 이분탐색이 틀린 손익분기를 낸다).

### 5-7. 매도 세금 기준 — 개인 / 매매사업자 / 미계산 (2026-07-28 도입)

시뮬레이터는 매도 세금 기준을 3종으로 나눈다. **기본값은 매매사업자**(사용자 전략 확정).

| 기준 | 세목 | 필요경비 | 단기 중과 |
|---|---|---|---|
| `individual` | 양도소득세 | **좁음** — 취득부대비 + 매도중개보수 | 1년↓ 70% / 2년↓ 60% |
| `dealer`(기본) | 사업소득 종합과세 | **넓음** — 위 + 대출이자·명도비·수리비·미납관리비 | **없음**(아래 §64 조건 제외) |
| `none` | 미계산 | — | — (세전 관점. 취득세는 취득원가라 유지) |

**매매사업자에게 단기 중과가 없는 근거**: 소득세법 §64(부동산매매업자에 대한 세액계산 특례)의
비교과세는 **'중과대상 주택'에만** 걸리고, 그 조항이 단기세율(§104①2·3)을 인용하지 않는다.
따라서 중과대상이 아닌 주택은 보유 6개월이어도 기본세율 누진표를 탄다 — 이것이 매매사업자의
핵심 이점이다(원문 검증 확정).

**비교과세(§64) 진입 조건**: 주택 & 조정대상지역 & 세대 2주택 이상. 진입하면
(종합소득세 / 다주택 중과 / 단기세율) 중 **가장 큰 세액**을 쓴다.
⚠ 비교 후보의 과세표준은 사업소득이 아니라 **양도소득 방식**(시행령 §122: 매매가액 −
§97 필요경비 − 기본공제 250만)이다 — 넓은 경비로 계산하면 세액이 과소해진다(낙관 금지).

**다주택 중과 가산율**(2026-05-10 재개): 2주택 +20%p / 3주택 이상 +30%p.
중과 대상은 **장기보유특별공제 배제**. 개인(`individual`) 모드도 이 중과를 적용한다 —
2026-07-28 감사 전까지 `transfer_tax()` 가 주택수·조정지역을 몰라 미적용이었고, 같은 페이지의
`static/dealsim.js`(신분 비교표)와 세후 순익이 **5,200만원** 갈렸다(3주택·조정·30개월 실측).

**전제 고지 의무**: `dealer` 는 **사업성(계속·반복성) 인정**을 전제한다. 등록만으로는 부인될
수 있고, 부인되면 양도소득으로 재분류돼 세액이 크게 는다(기본 시나리오 6개월 보유 실측:
세후 순익 3,800만 → 679만, 차이 3,121만 = 헤드라인의 82%). 다른 종합소득은 미반영이라
합산 시 세율 구간이 올라간다. 이 전제는 화면에 반드시 표시한다.

**단일 출처 계약**: 이 절의 규칙은 `src/bidsim.py`(파이썬)와 `static/dealsim.js`(JS) 두 곳에
구현돼 있고 `tests/test_dealsim_crosscheck.py` 가 두 구현의 일치를 강제한다. 세율·판정 조건을
바꾸려면 **이 문서 → 두 구현 → 교차검증 테스트** 순으로 함께 고친다.
