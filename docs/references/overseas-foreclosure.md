# 레퍼런스 — 해외 경매·차압 매물 사이트 (Zillow Foreclosure / Auction.com)

> 탐색 사이클 #5 (2026-07-03). 국내(지지·탱크) 외 해외 관점 벤치마킹으로 **오프라인 구현 가능한** 갭 발굴.
> 출처: zillow.com/foreclosures, auction.com (공개 페이지·웹서치, 데이터 크롤 아님 — 기능·UX만).

## 1. 핵심 기능 분해
| 사이트 | 강점 |
|---|---|
| **Zillow Foreclosure** | 단계별 필터(pre-foreclosure/auction/bank-owned), **과거 매매이력(price history)**, 사진 다수, 모기지 계산기, 지역 시장 트렌드, **저장 검색·알림** |
| **Auction.com** | 경매 특화, 실시간 갱신, 입찰정보·경매일정, 고급 검색, **물건 비교** |

## 2. 우리 현황 대비 갭 (web.py 라우트 기준)
현재 우리: 목록/상세/차익근거/취득세/방법론/통계(/stats)/캘린더(/calendar)/관심물건(/watchlist).
- ✅ 이미 있음: 경매일정(calendar), 관심물건(watchlist), 통계(stats), 필터(목록).
- ❌ 없음 & **오프라인 구현 가능**(기존 DB만, 좌표·라이브 불요):
  1. **물건 비교** — 관심/선택 물건 2~4개를 나란히(차익·최저가·시세·취득세·유찰·경고) 표로. (Zillow/auction.com compare)
  2. **CSV 내보내기** — 현재 필터·정렬 결과를 CSV로. 이미 report.to_csv 존재 → 웹 다운로드 엔드포인트만.
  3. **저장 검색(URL 프리셋)** — 자주 쓰는 필터 조합을 이름+URL로 저장/재적용.
- ⏸️ 없음 & **오프라인 어려움**(별도 결정/데이터 필요):
  - 지도 뷰(B3): 좌표 투영변환/지오코딩 필요 → **blocked**(QUESTIONS Q1).
  - 과거 매매이력(price history): 국토부 실거래를 물건별로 보존해야 → pipeline 확장 필요(후보 B).
  - 모기지/대출 계산기: 금리·상품 가정 필요(주관) → 우리 '객관' 원칙과 상충, 보류.

## 3. 배울 것 / 버릴 것
- 배울 것: **비교(compare)**와 **내보내기**는 투자자가 후보를 좁히는 실전 도구 — 우리 "콕 집어주는" 컨셉과 정합.
- 버릴 것: 모기지 계산기(주관적 가정), 화려한 사진 위주 UX(우리는 '조용한 chrome·큰 숫자').
