# 레퍼런스 분석 — 탱크옥션 (tankauction.com) · 2026-07-02 탐색 사이클 #1

> 기능·UX 벤치마킹 전용(데이터 크롤 아님).

## ① 핵심 기능 분해
- 검색: 종합·법원별·소재지·기일별·**역세권**·특화검색(용도지역·부실채권·취하변경), **지도검색**(카카오/네이버)
- 물건 상세: 등기부등본·감정평가서·세대열람·건축물대장·단지정보·시세 **원스톱** + 임차인 보증금 인수 여부 분석
- 통계: **매각통계·결과보고서·예정물건·조회수 TOP30**
- 교육: 동영상 강좌·유튜브·경매퀴즈(무료 → 유료 전환 퍼널)
- 알림: 실시간 경매결과·공매예보·기한부경매·배당기일

## ② UX 패턴
- 기능이 많은 대신 메뉴 카테고리를 촘촘히 세분화. 리포트형 통계 화면 별도.
- 3일 무료체험 → 유료 전환 퍼널(전화 인증 1회).

## ③ 데이터 표현
- 등기부 기반 "말소 안 되는 부분 + 임차인 보증금 인수 여부"가 권리분석의 핵심 표현.
- 낙찰가율 표준 산식 통계. AI 예측 브랜딩은 없음(권리분석·통계 포지셔닝).

## ④ 유료화
- 무료: 교육·뉴스·기본 검색 / 유료: 상세 물건정보·권리분석("선택보기"). 지지옥션보다 저렴 평가.

## ⑤ 우리가 배울 것 / 버릴 것
- **배울 것**: 물건 상세의 원스톱 서류 정리(우리 D/E 파서 자산과 방향 일치 — 상세페이지에
  "권리 근거" 섹션 강화), 매각통계/조회수 TOP 같은 **가벼운 통계 페이지**(우리 DB로 즉시 가능:
  지역별 평균 차익갭·스코어 분포·유찰 분포), 취하/변경 감지(우리 캐시 diff 자산으로 가능).
- **버릴 것**: 교육 콘텐츠 퍼널(범위 밖), 세대열람 등 로그인 필요 서류(운영자 전용).
