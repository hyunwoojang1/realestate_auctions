# 레퍼런스 분석 — 지지옥션 (ggi.co.kr) · 2026-07-02 탐색 사이클 #1

> 기능·UX 벤치마킹 전용(데이터 크롤 아님). 출처는 뉴스·앱스토어·비교 블로그 2차 자료 포함.

## ① 핵심 기능 분해
- 검색: 종합검색 + **지도검색** + 차량/공매 검색 병행
- 물건 상세: KB시세·국토부 실거래가·주변 실매물가 **3중 시세 크로스체크**, 권리분석 보고서
  (말소기준권리·인수금액 추정 시각화), 명도 리스크 평가(점유자 분석)
- **특수권리 13종 전문가 분석** — 유치권·법정지상권·선순위 가등기 등 (업계 유일 표방)
- **AI 낙찰가 예측(ALG)** — 30년 데이터로 예상낙찰가 + 회차별 유찰/낙찰 확률 (ALG 3.0)
- 알림: 실시간 개찰결과·물건 진행상태 푸시, 관심물건 관리, **경매 캘린더**
- 콘텐츠: 경매칼럼·주간 뉴스레터(스티비)

## ② UX 패턴
- 목록형 검색 + 지도검색 병행. 권리분석을 텍스트가 아닌 보고서/표 시각화로 제공.
- 불만: UI 노후(디자인 오래됨), 기기 대응 미흡, **업계 최고가 요금**(전국 연 ~115만원 언급).

## ③ 데이터 표현
- 낙찰가율 = 낙찰가/감정가 ×100 기준 통계. ALG 예상낙찰가를 회차별 수치로 제시.
- 인수금액·말소기준권리를 보고서 형태로 정리.

## ④ 유료화
- 기본 검색 무료 → 상세 권리분석·AI예측·특수권리 분석 유료. 지역/기간제 요금.

## ⑤ 우리가 배울 것 / 버릴 것
- **배울 것**: 시세 크로스체크를 한 화면에(우리는 국토부만 → V-World·건축물대장 결합 여지),
  회차별 유찰 확률 개념(우리 환금성 점수에 유찰횟수 이미 반영 — 노출 강화), 경매 캘린더,
  관심물건 알림의 웹 UI화(우리 V2 watchlist는 CLI/파일 기반).
- **버릴 것**: 전문가 수동 분석(무인 서비스 방향과 불일치), 유료 장벽(우리는 큐레이션 차별화).
