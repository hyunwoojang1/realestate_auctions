# 무료 격차 명세서 — 받을 수 있는데 안 받는 것 / 받아놓고 안 쓰는 것

> **지향점**(harness/AUDIT_CHARTER.md §5): 앞선 감사들이 "받은 것을 잘 저장했나"를 물었다면,
> 이 감사는 **"받을 수 있는데 안 받은 것"**과 **"받아놓고 안 쓰는 것"**을 찾는다.
> 유료 서비스가 보여주는 항목을 기준선 삼아 격차 목록을 만들되, 유료 사이트 **데이터 크롤은 금지**
> (LOOP.md 범위 잠금) — 공개 기능 소개 열람과 웹서치 벤치마킹만.
>
> 조사: 2026-07-23, 3관점 병렬(우리 호출 인벤토리 / UI XML·문서 정찰 / 유료 기준선).
> **라이브 탐침 0회** — 그날 크롤 예산 5,400+ 소진, 타 세션 크롤 진행 중이라 정적 분석만.
> 따라서 "무료로 열려 있는가"는 대부분 **UI XML 스키마 + 과거 라이브 기록에 대한 문서적 추론**이며,
> 실행 시 세션·선행호출 요구 같은 장벽이 나올 수 있다(불명은 불명으로 표기).

### 2-1. 현황조사서(임차인 전입일) — **최우선 격차** (P-08 · P-10)

## 5. 유료 서비스 대비 우리 위치 (기준선 조사)

- **대등하거나 우위**: 권리분석 자동판정(결정론적 규칙 + 회귀 테스트로 재현 가능), 복수 시세 크로스체크
  (국토부 + 네이버 KB/호가/전세 + 신뢰계수·2선 밴드 병기).
- **명확한 열위**: 등기부 요약(유료라 구조적), 인근 낙찰통계/실낙찰가율, 관련사건, 문건송달, 예상 배당표.
- **가치는 높은데 커버리지가 낮음**: 전입세대(현황조사서) — 코드는 있는데 안 돌린다(§2-1).
