차익 스코어 방법론

"차익 유력"을 어떻게 계산하는지, 그리고 스코어가 실제 수익으로 이어지는지(백테스트)를 공개합니다. 산식과 검증을 숨기지 않는 것이 이 도구의 신뢰 근거입니다.

1. 종합 공식

차익_스코어 = ( 가격갭 ×{{ '%.2f'|format(cfg.w_gap) }} + 권리 ×{{ '%.2f'|format(cfg.w_rights) }} + 환금성 ×{{ '%.2f'|format(cfg.w_liq) }} ) × 신뢰계수
실질취득원가 = 최저입찰가 + 취득세 + 명도비 + 수리비 + 인수금액
가격갭 = (추정시세 − 실질취득원가) / 추정시세

2. 안전장치 (핵심)

⚠ 하드게이트: 인수금액/최저가 > {{ '%.0f'|format(cfg.assumed_ratio_gate * 100) }}% 또는 치명적 특수권리(유치권 등) → 권리 점수 0, 최종 스코어를 상한 {{ '%.0f'|format(cfg.gate_ceiling) }}점으로 강등('위험'). 가격갭이 커도 권리 폭탄이 상위 노출되는 것을 막습니다.
⚠ 권리미확인 게이트: 물건상세 권리분석이 안 된 물건(라이브 크롤)은 갭이 커도 '차익 유력'을 부여하지 않고 '권리미확인'으로 표기합니다. 표본 게이트: 실거래 <{{ cfg.min_comps_price }}건이면 시세추정불가, '차익 유력'은 ≥{{ cfg.min_comps_confident }}건에만.
